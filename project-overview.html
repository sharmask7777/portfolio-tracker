Why Portfolio Tracker was Built

Mainstream Indian investment apps (Zerodha Coin, Groww, Kuvera) treat mutual funds as black boxes. They suffer from four fatal blind spots: zero multi-fund stock look-through, outdated capital gains tax engines that ignore the landmark Finance (No. 2) Act 2024, no multi-PAN family aggregation, and reliance on invasive cloud servers with zero offline resilience.

  • •
    The Hidden Overlap Trap: An investor holding 4 diversified equity funds often unknowingly concentrates 20%+ of their net worth in just 2 stocks (e.g. HDFC Bank & Reliance). Apps show fund returns, never aggregate stock exposure.
  • •
    Obsolete Tax Computations: Budget 2024 fundamentally bifurcated Indian taxes on July 23, 2024 (12.5% LTCG, 20% STCG, ₹1.25L exemption, grandfathering deemed costs, Section 50AA debt slab taxation). Most apps still compute outdated rates or lack Schedule CG Table F accrual tables.
  • •
    Siloed Investor PANs: Real Indian families invest across spouse, parents, and minor folios. Apps force multiple logins or blend taxes into a single unfiled entity.
  • •
    Privacy & Cloud Dependency: Requiring live broker passwords or uploading financial statements to 3rd-party commercial clouds with tracking. Zero offline capability when server is down.

Statement Upload & Multi-Tier Transport

Client → portfolio-api (POST /api/v1/cas/upload)

The user selects a password-protected CAMS or KFintech CAS PDF on the React Web SPA or picks it on the Mobile App (`expo-document-picker`). The password is encrypted, and the file is streamed via multipart form data to the Axum API gateway.

Why this is unique:

On mobile, if the self-hosted Docker server is unreachable, the statement is not lost. It enters the SQLite `sync_queue` outbox with encrypted credentials and auto-retries when connectivity resumes.

The Clean-Slate Reconstruction Invariant

Because Indian Consolidated Account Statements (CAS) are cumulative historical snapshots rather than delta feeds, appending transactions into a database inevitably causes phantom duplicate purchases, broken running balances, or inverted signs during scheme mergers.

The Rule: When a CAS statement touches a Folio, the worker executes Clean-Slate Reconstruction: all pre-existing ledger entries, cached valuation checkpoints, and intermediate lots for that specific folio are cleared in an atomic database transaction. The entire historical sequence is then streamed afresh and verified against the statement's authoritative Running Balance.

Zero-I/O Functional Engine & Numerical Rigor

Why `portfolio-core` forbids unsafe code, contains zero I/O dependencies, and guarantees deterministic financial calculations.

Zero-I/O Invariant

ArchUnit Dependency Oracle

In enterprise systems, financial business logic frequently gets contaminated with database queries (`sqlx`), network calls (`reqwest`), and asynchronous runtime handles (`tokio`), making unit testing slow, flaky, and non-deterministic.

In Portfolio Tracker, architecture is enforced programmatically by tests. `architecture_invariants_test.rs` reads `portfolio-core/Cargo.toml` at test-time and asserts:

// ArchUnit programmatic barrier in portfolio-core: let forbidden = ["tokio", "sqlx", "reqwest", "redis", "actix", "axum", "diesel", "postgres"]; for &dep in &forbidden { assert_ne!(dep_name, dep, "portfolio-core violates Zero-I/O!"); } assert!(lib_rs.contains("#![forbid(unsafe_code)]"));

Result: All calculations in `portfolio-core` are pure functions: f(holdings, market_navs) → PortfolioValuation with 0ms execution time.

Numerical Analysis

Hybrid Brent-Dekker XIRR Solver

The Extended Internal Rate of Return (XIRR) satisfies the Net Present Value polynomial equation:

$$f(r) = \sum_{i=0}^{n} C_i (1 + r)^{-\frac{t_i - t_0}{365}} = 0$$
Four Numerical Safeguards:
  • Logarithmic Exponentiation: Evaluates $(1+r)^{-w_i} = \exp(-w_i \ln(1+r))$ to prevent overflow on long horizons.
  • Magnitude Normalization: Divides all cash flows by $\max |C_i|$ to avoid floating point saturation when analyzing ₹Crores.
  • 30-Day Guardrail: Prevents mathematical distortions on short-duration investments by falling back to absolute returns.
  • Damped Newton-Raphson Fallback: Multi-guess fallback with singularity damping if bracket root search fails.

Mobile & Decoupled Offline-First Architecture

A native React Native & Expo mobile companion built for zero-dependency portability and sub-100ms startup.

Decoupled Daily Valuation

Zero-Server Mobile Autonomy

Most self-hosted mobile apps fail the moment you leave your home Wi-Fi because your home NAS / Docker server isn't exposed to the public internet.

Portfolio Tracker solves this via Decoupled Daily Valuation:

  • The phone holds your folios, asset quantities, and AMFI codes locally in expo-sqlite.
  • When opening the app on cellular data, it queries the public AMFI mutual fund feed (api.mfapi.in/mf/<amfi_code>) directly over HTTPS.
  • It computes units × current_nav on-device, updating today's valuation and daily change without needing your server to be reachable!
Frictionless Security

Hardware Biometrics & QR Pairing

No typing long JWT tokens or server URLs on mobile touchscreens:

  • QR Handshake: Click "Pair Device" on the Web Dashboard. Axum emits a short-lived, single-use cryptographically random token via /api/v1/auth/pair/init.
  • Camera Scan: Mobile camera scans QR code, calls /api/v1/auth/pair/claim, and obtains a long-lived device token.
  • Hardware Keystore: Token is persisted inside the device hardware security module (iOS Keychain / Android KeyStore) via expo-secure-store.
  • Biometric Gating: App launches are unlocked via Face ID / Touch ID / BiometricPrompt via expo-local-authentication.

The 8 Static Build-Time Guardrails

A zero-tolerance engineering discipline guaranteeing that defects, untyped code, dead exports, and architectural drift fail loudly at build time.

Guardrail 1 proptests.rs • golden_tax

The Invariant Oracle Law

Agents must NEVER "fix" a test failure by changing assertion numbers in property tests or golden fixtures. Tests mathematically codify ground-truth statutory law. If an oracle fails, the algorithm is defective. Fix the algorithm, never the oracle.

Guardrail 2 tsconfig.app.json

The Zero-Any & Compiler Strictness Mandate

Zero `any` allowed in TypeScript. Enforces `strict: true`, `noImplicitAny: true`, `noUncheckedIndexedAccess: true` (array lookups evaluate to `T | undefined`), `exactOptionalPropertyTypes: true`, and isolated modules.

Guardrail 3 export_bindings.rs

Cross-Stack Type Contract Parity

Frontend and Mobile types are auto-generated directly from Rust backend structs via `cargo test --package portfolio-api --test export_bindings`. Git diff check (`git diff --exit-code frontend/src/types/generated`) blocks PRs if types drift.

Guardrail 4 portfolio-parity

Differential Parity Engine

The differential parity runner continuously tests benchmark scenarios between Rust and TypeScript engines, validating: Units Δ ≤ 0.0001, Money Δ ≤ ₹0.01, and Returns Δ ≤ 10⁻⁶.

Guardrail 5 mock_portfolios.rs

10+ Hermetic Mock Portfolios

Every edge case is codified: Scheme consolidation, zero-holding redemptions, partial FIFO redemptions, stock look-through, pure debt/liquid, alternative assets (SGBs, physical gold), multi-PAN family switching, grandfathering, and ELSS 3-year lock-ins.

Guardrail 6 check-privacy-and-pii.py

Static Anti-PII & Privacy Scanner

Pre-commit hook scans all tracked repository files, barring real-world Indian PAN formats, real customer names, bank details, or CAS PDF/JSON statements from ever being committed. Synthetic test data only!

Guardrail 7 knip --production

Dead-Code & Dependency Auditing

`knip` runs during `pnpm build:verify`. Zero unused files, zero dead exports, and zero unreferenced dependencies permitted in production bundles. Keeps bundle size minimal.

Guardrail 8 eslint-plugin-boundaries

Architectural Boundary Isolation

Layer isolation: Utility modules cannot import UI components; UI domains (`Analytics`, `Tax`, `Dashboard`, `Family`) cannot import private internals of sibling domains; circular dependencies are rejected.
