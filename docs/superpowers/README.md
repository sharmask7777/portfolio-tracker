# Specs, Plans & SDD Execution Logs

This directory organizes design-to-implementation artifacts chronologically by feature:

- **[specs/](specs/)** — Design specifications (`YYYY-MM-DD-<feature>-design.md`) defining requirements, architecture, and invariants before implementation.
- **[plans/](plans/)** — Step-by-step implementation plans (`YYYY-MM-DD-<feature>.md`) derived from specs.
- **[sdd/](sdd/)** — Spec-Driven Development (SDD) execution ledgers (`YYYY-MM-DD-<feature>/`), containing per-task briefs (`task-N-brief.md`), completion reports (`task-N-report.md`), `progress.md` ledgers, and review diffs.
