## 3. Mathematical Formulations & Drag Attribution

### A. Terminal Liquidation & Real Purchasing-Power XIRR
The terminal net cash flow is already formulated in `routes/portfolio.rs`:
$$\text{Terminal Cash Flow} = \max(0, \text{Gross Portfolio Value} - \text{Total Estimated Tax} - \text{Exit Loads})$$
`portfolio-core` solves for $r_{\text{post-tax}}$ via `calculate_xirr(&post_tax_flows)`.
The evolutionary addition integrates CPI inflation ($i_{\text{inflation}}$, default 6.0%) via the Fisher equation:
$$r_{\text{real}} = \frac{1 + r_{\text{post-tax}}}{1 + i_{\text{inflation}}} - 1$$

### B. Sequential Layer Exclusion (Drag Teardown)
Because XIRR is an iterative root-finding solution ($f(r) = 0$), drag components cannot be derived by scalar arithmetic. The engine decomposes drags via sequential terminal value adjustments:
1. $r_0 = \text{solve\_terminal\_xirr}(\text{Gross Value})$ [Nominal XIRR]
2. $r_1 = \text{solve\_terminal\_xirr}(\text{Gross Value} - \text{Tax}_{\text{50AA}})$ [Debt Slab Drag: $\Delta_{50\text{AA}} = r_0 - r_1$]
3. $r_2 = \text{solve\_terminal\_xirr}(\text{Gross Value} - \text{Tax}_{\text{50AA}} - \text{Tax}_{\text{112A/111A}})$ [Equity Capital Gains Drag: $\Delta_{\text{Equity}} = r_1 - r_2$]
4. $r_3 = \text{solve\_terminal\_xirr}(\text{Terminal Net Value}) = r_{\text{post-tax}}$ [Cess & Exit Drag: $\Delta_{\text{Cess}} = r_2 - r_3$]
5. $r_{\text{real}} = \frac{1 + r_{\text{post-tax}}}{1 + i_{\text{inflation}}} - 1$ [Inflation Drag: $\Delta_{\text{Inflation}} = r_{\text{post-tax}} - r_{\text{real}}$]

*Loss State Invariant:* If net unrealized capital gains $\le 0$, all statutory tax drags are identically $0.00\%$, while $\Delta_{\text{Inflation}}$ continues to reflect purchasing-power deflation.
